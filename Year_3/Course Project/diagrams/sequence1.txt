title Диаграма 1: Откриване и филтриране на игри по жанр

actor Потребител
participant "Frontend (UI)" as UI
participant "RAWG API" as API

Потребител->+UI: Отваря началната страница на приложиението
UI->+API: GET /games (извличане на игри)
API-->UI: Връща JSON масив с игри
UI-->Потребител: Изобразява списъка (game cards)

Потребител->UI: Филтрира игрите по жанр (примерно по "Action")
UI->API: GET /games?genres=action
API-->-UI: Връща филтриран JSON масив
UI-->-Потребител: Изобразява филтрирания списък с игри
